## Running code nexus demo env

To run the code nexus demo environment,  you should run:

> npm ci

> npm run start:nexus


## Running the code nexus web site

To run the code nexus documentation site, you should run:

*Note: only do the install command if you havent run already*
> npm ci

> npm run start:web
