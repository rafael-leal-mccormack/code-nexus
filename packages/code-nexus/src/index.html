Templates Demo

Code Nexus provides two ways to use templates: the built-in templating mechanism via component properties, or direct content manipulation.

Method 1: Using Built-in Template Support

The component has a built-in template system that can be enabled with the enable-templates property and passing an array of template objects to the templates property. This renders template buttons in the footer.
