Integration Note:

Code Nexus has built-in code formatting capabilities that can be easily enabled in your application. The formatter uses Prettier under the hood to beautify HTML, CSS, and JavaScript code.

To enable formatting in your CodeNexus instance:

  1. Set the enable-formatting attribute or enableFormatting property to true
  2. Optionally configure formatting options with the formatting-options property
  3. The "Format All" button will appear in the component's footer toolbar
